# CarePill 文档中心

> CarePill —— AI 驱动的老人用药管理 Flutter 应用。
> 当前阶段：**Android 种子用户版已完成代码修复，进入真机验收**。文档描述可能随实现演进，具体契约及验收状态以对应更新和测试为准。

## 当前进度（对齐 docs/08 里程碑）

- ✅ M0：Riverpod + go_router + Drift 全部建表 + OpenAI 兼容 AIClient + 通知链路 + 适老化主题（三档字号）+ 四 Tab 骨架 + CI（analyze/test/分层检查）
- ✅ M1：药品/计划 CRUD、任务展开与状态机、提醒链路、模型管理、AI 助手、四 Tab、首次引导
- ✅ 扫码查药：免费 openFDA 按 GTIN 查询、强制核对后填写保存；无需 AI 配置，国内覆盖有限，见 11。
- ✅ Android 种子可靠性修复：WorkManager 每日补偿、开机恢复、权限状态引导、备份覆盖回滚与密钥策略、日志隐私
- 🔨 真机验收：Android 12/13+ 权限、锁屏/重启/强停、国产 ROM 省电策略、连续数日后台续排
- ⬜ 发布签名：准备正式 keystore 后复制 `android/key.properties.example` 为 `android/key.properties`

## 产品一句话

让老人"说句话、拍张照"就能管好吃药：AI 记住药品和吃药时间，到点主动提醒，随时回答"我今天吃药了吗""这个药怎么吃"这类问题。

## 核心约束（来自需求确认）

| 约束 | 说明 |
| --- | --- |
| 无用户系统 | v1 不做账号/登录/云同步，全部数据本地存储 |
| 模型自带 | 不内置任何大模型服务，用户在设置中自行添加模型（OpenAI 兼容接口：填地址、密钥、模型名即可用） |
| 目标用户 | 老年人直接使用，适老化是一等公民需求，不是皮肤 |
| AI 驱动 | 药品录入、提醒播报、问答、统计解读等核心环节尽量由 AI 承担 |
