# 02 功能规划

优先级定义：

- **P0（MVP）**：没有它产品不成立，第一个可用版本必须包含。
- **P1**：核心体验增强，MVP 后立即做（对应路线图 M2）。
- **P2**：打磨与扩展（对应路线图 M3 及以后）。

## 2. 分模块详细说明

### F1 药品管理（药箱）

- 字段：名称、剂型（片剂/胶囊/口服液/贴膏/喷剂/注射…）、规格（如 0.1g×30 片）、单位（片/粒/毫升/喷…）、备注、照片（可选，拍药盒存档）。
- 状态：**在用 / 已停用**（不物理删除，保留历史记录完整性；删除走二次确认，级联提示会影响历史统计）。
- 排序：按"下一次服药时间"排序，最紧急的排最前。
- 来源标记：手动录入 / AI 拍照识别（保留识别原始 JSON，便于纠错与回溯）。

### F2 用药计划（Schedule）

一个药品可以有多个计划（如"降压药"早 8 点、晚 8 点各一次 = 同一药品两条计划，或一条计划带两个时刻，建模见 05 文档）。

- 频率类型：
  - **每天**（最常见，默认）；
  - **指定星期**（一三五）；
  - **间隔 N 天**（如隔日一片）；
  - **按需**（不进提醒队列，只在打卡时可选，如止痛药）；
- 每个时刻：时间 + 本次剂量 + 餐前/餐中/餐后（可选标签）。
- 计划支持暂停与恢复（住院/外出时）。

### F3 服药打卡（Dose Record）

- 每天为每条生效计划生成一条**服药任务**（计划 × 日期展开，见 05 文档）。
- 状态机：`待服 → 已服 / 跳过 / 漏服`（判定规则见 06 文档）。
- 打卡入口：通知按钮、首页大按钮、AI 语音/文字指令。
- 已服记录可撤销改判；支持补记（"昨天晚上的忘了记"）；补记与按点打卡在记录上区分标记，供统计与 AI 回答时区分。

### F4 提醒（详见 06 文档）

- 到点：本地通知（横幅+铃声）+ 可选全屏提醒页 + TTS 播报"该吃 8 点的降压药了，一次 1 片"。
- 升级：X 分钟未确认 → 重复提醒（次数与间隔可配）。
- 兜底：重启恢复、时区处理、厂商 ROM 保活引导。

### F5 AI 助手（对话）

定位：**像家里晚辈一样懂你用药情况的小助手**，不是通用聊天机器人。

- **事实问答（P0）**：通过工具调用查本地数据后回答——
  - "我今天吃药了吗？" → 逐项列出今天各次任务状态；
  - "下一个要吃什么？" → 最近一次待服任务；
  - "我血压药还剩多少天？"（P2，依赖库存统计）。
- **代办操作（P1）**："帮我记上刚才吃过药了" → AI 调用打卡工具 → 回复确认。涉及写操作时，工具事务提交后立即由 UI 呈现可撤销的操作条，续答失败保留成功事实。
- **用药咨询（P1）**：仅基于已录入药品的说明书字段与通用常识，用大白话解释"饭前吃是什么意思""漏了一次怎么办"（通用指引）；超出边界一律引导看说明书/问医生（见 03 文档安全护栏）。
- **闲聊兜底**：温和拒绝并拉回用药主题。
- 支持连续多轮；对话历史本地保存、可清空。

### F6 拍照识别（P1）

- 主流程：拍照/相册 → 视觉模型提取结构化信息（名称、规格、用法用量、频次、注意事项）→ **用户确认/修改** → 建卡 + 预填计划。
- 识别结果永远是"草稿"，绝不经确认直接写入。
- 详情见 03 文档第 6 节。

### F7 语音交互（P1）

- 助手页常驻麦克风大按钮：按住说话 → STT → AI → TTS 播报回答。
- 首页提供"问一问"语音入口。
- 提醒播报后可选语音回复"吃了"完成打卡（P2）。

### F8 模型管理（P0，产品差异化核心）

- 用户自行添加模型：配置项与连通性测试见 03 文档第 2 节。
- 支持多个配置并存，按能力指定用途：对话用 A、视觉识别用 B。
- 典型接法（文档里给引导文案）：DeepSeek、通义千问、Kimi、智谱、OpenRouter、本地 Ollama 等所有 OpenAI 兼容服务。
- 无可用模型时：提醒、打卡、手动管理一切可用，AI 功能入口显示引导页。

### F9 统计与报告（P1）

- 服药日历（按天视图：绿=全服、黄=有跳过、红=有漏服）；
- 近 7/30 天依从率（已服/应服）；
- 漏服清单；
- AI 周报（P2）：把统计数据交给对话模型生成一段大白话总结，可复制/分享给子女。

### F10 数据与设置

- 设置项：字体大小档位（标准/大/特大，默认"大"）、TTS 开关与语速、提醒提前量、升级提醒次数与间隔、每日提醒静默时段（如深夜不提醒按需药）。
- 数据导出/导入：单文件 JSON（含药品、计划、记录、设置、显式长期记忆；**不含** API 密钥，密钥随配置导出需单独确认）。

### F11 首次启动引导（P0）

三步：① 欢迎页（超大字说明这是干什么的）→ ② 添加模型（提供各家填写示例，可跳过——跳过后仍可手动管理）→ ③ 添加第一个药品（手动或拍照）。完成后进入首页。

Agent 连续对话、持久摘要、显式记忆及按住录音/松开发送的已实现规则以 03、05、07 文档更新为准；验收状态见 10。
